# 🍫 ChocoBook's®

Site de uma plataforma fictícia de livros digitais, criado para o trabalho de **Língua Portuguesa** no formato *Shark Tank*. O projeto foi realizado em grupo, mas **todo o site (HTML, CSS e organização do projeto) foi desenvolvido inteiramente por mim**, Guilherme Silva Cotrim.

## 📖 Sobre o projeto

O ChocoBook's é a proposta de um catálogo online de livros em que o leitor pode abrir as obras direto no navegador. A ideia do negócio inclui ainda um serviço de tradução: qualquer pessoa pode se candidatar para ser tradutora ou enviar o próprio livro para ser traduzido.

## ✨ Funcionalidades

- Página inicial com o catálogo dividido em três categorias:
  - **Auto-Ajuda e Neurociência**
  - **Terror**
  - **Ficção**
- Capas clicáveis que abrem o livro em PDF em uma nova aba
- Setas de navegação em cada categoria (decorativas, levam a uma página de aviso)
- Menu de navegação com links para:
  - **Seja Um Tradutor** e **Traduzir Meu Livro**, ambos via Google Forms
  - **Contato**, que leva à página com os integrantes do grupo
  - Livros, Categorias e Cadastro/Login, que levam a uma página de "indisponível" (funcionalidades apenas ilustrativas)
- Logo e favicon personalizados
- Um easter egg escondido na logo 🤫

## 🛠️ Tecnologias

- HTML5
- CSS3

Sem frameworks, bibliotecas ou back-end: é um site estático.

## ▶️ Como executar

1. Clone o repositório:
```bash
   git clone https://github.com/gscotrim2006/trabalhoDePortugues_ShankTank.git
```
2. Entre na pasta do projeto:
```bash
   cd trabalhoDePortugues_ShankTank
```
3. Abra o arquivo `index.html` no navegador.

Ou se não quiser clonar nada (clique com o botão do meio para abrir numa nova aba):
